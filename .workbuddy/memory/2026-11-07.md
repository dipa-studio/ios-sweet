# 2026-11-07

## MT6983 GPU CSF: A and C collapsed into one rule (bit 9)

- Re-read the whole evidence log against the address alphabet instead of
  against build order. A single law fits every access this port has ever made:
  an MCU access hangs iff **bit 9** of the address is set. 21 points, zero
  exceptions, covering reset fetch, running fetch, data reads and data writes.
- The old "512-byte aligned but not a 4 KiB page base" reading is dead: the two
  data-read hangs that motivated it (`0x01001AF8` from 2369, `0x01001BC4` from
  2376) are not 512-aligned at all. They are bit 9 = 1.
- `as_fault = 0` on both sides of the wall (2394 runs, 2391/2393 hang), so the
  table walk succeeds and the transaction stalls downstream. That explains why
  nine attribute experiments (2374 shareability, 2378 AP, 2380/2393 MemAttr,
  2393 vendor leaves) changed nothing.
- Because every leaf is 4 KiB aligned, `PA bit 9 == VA bit 9` for every byte of
  every section, so no mapping change can move the wall - which is why 2382's
  1.2 MB relocation did nothing.
- Question C answered without a new flight: disassembling the vendor reset
  handler shows 2376's unpatched firmware stops at `0x010019dc ldr r0,[pc,#0x1e4]`
  reading `0x01001BC4` (bit 9 = 1). It got there through a successful
  `bl 0x01003126`, so the handler does run; it dies on a literal read.

## 2396 flew: the bit-9 rule is narrower than section 40 claimed

- One boot, one ladder at 0x0100E000 (entry 0x0100E001, 2394's encoding):
  marker 1 -> read 0x04000200 (shared), marker 2 -> 0x02000200 (stack),
  marker 3 -> 0x01001200 (code). `input_va = 3`: the shared and stack reads
  RETURNED, only the code read stalled.
- So "an access hangs iff bit 9 is set" is wrong as a general law; all 21 points
  behind it sat in the code section. Correct form: **bit 9 inside a page the MCU
  can execute stalls; a non-executable section does not have the property.**
  Section 40 now carries a correction pointing at section 42.
- Remaining difference between the working stack leaf and the stalling code leaf
  is AP[2] and XN. 2378 already cleared AP[2] on the code pages (no change), so
  XN is the only leaf field never varied. 2397 = same ladder, code mapped
  non-executable, read 0x01001200 decides.
- Recorded confound: the three probes also differ in physical page. 2382 moved
  the code section by 1.2 MB without moving the wall, which argues PA is not the
  variable, but that is an argument, not a measurement.
- Tests 269/3 skipped. Commits: 1f999a2 (implementation), plus this doc round.
