## 2404 built 12:45 — force the page walk to read a descriptor at PA bit 9 = 1

- Design shift after the user's warning: 0x08000000 is (per MT6983 lore) inside the
  Cortex-M7 window decoders, so a no-marker result there would be ambiguous. Mirror
  the section at 0x06040000 instead: L2[48] at 0x180 (bit9=0), fresh L3 page indexes
  0x40..0x4F at offsets 0x200..0x278 (all bit9=1). Reading 0x0604E400 then costs a
  descriptor fetch at bit9=1 while VA/PA bit9 are both 0.
- Leaf kept VALID on purpose: an unmapped entry faults the moment the walk succeeds
  and would throw away the store test, which is the only direction never measured.
- Ladder 88 B (tools/matisse-csf-ladder2404.S): read 0x0100E400 (warm, 0x0f10f857),
  read 0x0604E400 (cold walk), store 0x5a5a5a5a -> 0x04000200 + DSB SY, read back,
  park. All reads store to shared+12 because shared+16 is `groups` and shared+20 is
  `group_stride` (validated as a length — 0x5a5a5a5a there would reject a good run).
- DSB is load-bearing: normal non-cacheable stores are posted, so without it marker 3
  appears even if the write never reached AXI.
